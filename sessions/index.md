# Sessions: the handoff catalog

Every session handoff gets one row here. **Read this file first**, then open only the note that
matches what you are working on. Never open the notes one by one.

> **For your AI:** at the start of a session, once the topic is clear, check this catalog. If a
> row matches, read that handoff before doing any work. It carries decisions already locked and
> state still running. Redoing settled work is waste, and ignoring a locked decision silently
> undoes it.
>
> **Writing rule:** every `session-handoff` run **must** add a row here, in the topic table and
> in the chronological table. A handoff that is not in the catalog is invisible.
